Filename/extension glyphs and light/dark colors are a bundled snapshot of
nvim-tree/nvim-web-devicons, commit ec309a0eaff6ea967e58c275996155ab5c16938d,
from the locally installed Neovim plugin. MIT license included in LICENSE.
Source: https://github.com/nvim-tree/nvim-web-devicons

icons.json contains the upstream icons-default/icons-light filename and extension
maps, exported using Neovim's vim.json.encode. No Neovim runtime is required.
Font glyphs are rendered using the installed Nerd Font; no font is redistributed.
