# Pip Rot icon

`pip-rot.png` is the app's runtime Dock/window icon. Generated with the built-in
imagegen tool with a transparent background, then copied here without editing.
Qt loads it from this directory at startup; no `.app` bundle is needed for the
running process's Dock icon. A pinned Dock launcher is a separate packaging task.

## Generation prompt

Use case: logo-brand. Asset type: macOS Dock application icon for a playful personal file browser called Pip Rot. Create one bold memorable icon: a slightly rotten vivid red apple with a dark bruised patch and a cheeky friendly little lime-green worm peeking out of a round hole, tiny brown stem and one green leaf. Polished illustrated 3D clay-like app icon, charming irreverent hacker mascot, simple chunky shapes, crisp silhouette and high contrast, legible at 32px. Centered single subject, front three-quarter view, fills about 85% of square canvas, soft restrained shading, subtle grounding shadow only. Transparent background with real alpha; no background tile, no text, no letters, no watermark. The apple should look like a whole organic fruit, not Apple's corporate logo; round worm hole rather than a bitten silhouette.
